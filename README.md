# PDF 办公工具箱

一个功能强大的 PDF 桌面工具，无需安装 Python 环境，下载即用！

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 📎 **合并PDF** | 将多个 PDF 文件合并为一个 |
| ✂️ **拆分PDF** | 按页拆分 PDF 文件 |
| 📦 **压缩PDF** | 减小 PDF 文件体积 |
| 📝 **PDF转文字** | 提取 PDF 中的文字内容 |
| 📊 **PDF转Excel** | 提取 PDF 中的表格数据 |
| 🖼️ **PDF转图片** | 将 PDF 每页转为 PNG 图片 |
| 📸 **图片转PDF** | 将多张图片合成为一个 PDF |
| 💧 **添加水印** | 为 PDF 添加文字水印 |

## 🚀 使用

1. 从 [Releases](https://github.com/zhoubiao321-spec/pdf-toolkit/releases) 下载最新版
2. 双击运行 **PDF工具箱.exe**
3. 选择功能开始处理

## 🛠️ 技术栈

- **Python 3.12** - 核心语言
- **PyPDF / pdfplumber** - PDF 解析
- **ReportLab** - PDF 生成
- **Pillow** - 图片处理
- **Tkinter** - 桌面 GUI
- **PyInstaller** - 打包为独立 exe
