 PDF 办公工具箱 - 样例文件
===================================

本文件夹包含 PDF 工具箱的功能演示文件。

使用方法：
1. 打开 PDF工具箱.exe
2. 选择所需功能
3. 选择输入文件和输出位置
4. 点击处理

功能列表：
- 合并PDF：将多个PDF合并为一个
- 拆分PDF：将PDF按页拆分为多个文件
- 压缩PDF：减小PDF文件体积
- PDF转文字：提取PDF中的文字内容
- PDF转Excel：提取PDF中的表格数据
- PDF转图片：将PDF每页转为图片
- 图片转PDF：将多张图片合成PDF
- 添加水印：为PDF添加文字水印
